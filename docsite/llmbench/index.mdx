**Aistee** (formerly LlmBench) is an early-stage Kotlin Multiplatform AI workspace. Android 8.0+ is the current client; desktop and iOS are **planned**, not shipped.

## Boundaries worth knowing

Web provider logins and API keys are different authorization routes. Provider-owned web sessions are not silently converted to API credentials. Native keys are encrypted at rest, and local projects do not require an Aistee account.

Some provider login flows are only partially compatible with Android embedded WebViews. The [provider matrix](/llmbench/providers) distinguishes verified behavior from device testing still needed.
