---
title: "Build Aistee for Android"
description: "Build the current Aistee Android client with Android Studio, JDK 21, and SDK Platform 37."
sidebarTitle: "Quickstart"
---

Aistee currently ships on **Android 8.0+ (API 26)**. The Android module compiles with SDK 37 and targets API 36; Java source/target compatibility is 21. Check [app/build.gradle.kts](https://github.com/travnie/aistee/blob/main/app/build.gradle.kts) before pinning future tooling.

<Steps>
  <Step title="Clone the renamed repository">
    Run `git clone https://github.com/travnie/aistee.git` and enter the `aistee` directory.
  </Step>
  <Step title="Configure Android Studio">
    Open the repository root. Use JDK 21 for Gradle and install Android SDK Platform 37 when requested.
  </Step>
  <Step title="Build debug APK">
    Run `./gradlew :app:assembleDebug` (Windows: `gradlew.bat :app:assembleDebug`).
  </Step>
  <Step title="Run">
    Use a device/emulator on API 26 or newer. The build output is under `app/build/outputs/apk/`.
  </Step>
</Steps>

For ordinary use, [download the rolling signed APK](https://github.com/travnie/aistee/releases/download/aistee-latest/aistee.apk). For development rules, tests, and architecture see [the upstream README](https://github.com/travnie/aistee#development) and [documentation index](https://github.com/travnie/aistee/blob/main/docs/README.md).

<Warning>
  An Aistee WebView login is not an API subscription or API credential. Provider auth requirements and limits still apply.
</Warning>
