Aistee moves quickly. This page summarizes the **main-branch** product, not every experiment in an open pull request.

## Already implemented

- Provider-owned WebViews with persistent sessions, uploads, favorites, selected generation/unread indicators, and memory-pressure handling.
- Native/API Gemini, OpenAI, Claude, and supported compatible gateway routes, with streaming and provider-scoped history.
- Local projects, Library assets, imports/exports, Markdown and Docbench previews.
- Tools, token counting, QR generation, trusted skill execution and sandbox boundaries.
- Adaptive Material 3 UI, home-screen conversation widgets, notifications, and native Direct Reply.
- Encrypted API key storage, app lock, privacy controls, and no Aistee account requirement.

## Work still in progress

- Verify sign-in, file uploads, and activity probes on partially supported embedded providers.
- Extend explicit browser-backed auth handoffs only where a provider supports them.
- Expand agent/Codebench integrations and test large-screen/long-chat performance.
- Keep local data, secrets, WebView host boundaries, exports, and tool permissions under regression tests.
