## Find the right source

- **Install or use:** start with the project's introduction or quickstart when available, then follow its releases.
- **Build or contribute:** follow the linked repository README and maintained technical docs. Those files own exact build commands, API contracts, and release status.
- **Verify a capability:** trust tested hardware results and merged main-branch behavior, not an open PR or an old screenshot.
