[Intent Keyboard](https://github.com/travnie/twojstar/tree/main/intent-keyboard) explores **intent-first input**: turn rough notes into natural text while controlling tone, translation, and facts that must not change.

It is an experiment in the shared workshop, **not** a claim of a released production keyboard. Check its source directory and tests for current implementation details; it is not a standard asset in the rolling release.
