**Loopling** is an unofficial fan-made animated desktop pet, built as original artwork for ChatGPT and Codex Pets. Its states include idle, walking, waving, jumping, waiting, working, reviewing, and failure, plus directional gaze frames.

## Install

From [`pets/loopling`](https://github.com/travnie/twojstar/tree/main/pets/loopling), use `scripts/install.ps1` on Windows or `scripts/install.sh` on macOS/Linux. The installable files are `pet/pet.json` and `pet/spritesheet.webp`, stored under the user's Codex Pets directory. Restart ChatGPT and select Loopling in **Settings → Pets** where that feature is available.

## Reproducible artwork

The project includes procedural source art, generator scripts, a validated animation atlas, and GIF previews. For the current sprite contract and regeneration commands, see [Loopling's README](https://github.com/travnie/twojstar/blob/main/pets/loopling/README.md).
